# exo2ego-papers

A reading list on exo-to-ego video generation, paired ego+exo data, and the 3D capture, human-pose, auto-labelling and robot-learning work around it.

| file | what it holds |
|---|---|
| `PAPERS.md` | all 329 entries in 12 categories, each with paper, project page and code links |
| `papers.tsv` | the same as columns (category, title, arXiv id, links, checked) |
| `CORE.md` | the checked subset on exo-to-ego, policies and benchmarks, with one headline number per paper taken from its abstract |

A check mark in `PAPERS.md` means the entry was checked against arXiv on 16 Nov 2026 (id, title, date, authors, abstract). Unmarked entries are leads: titles come from the fetched page, and an arXiv id is shown only when arXiv's own title for it matched. Licences were not checked; read the licence on any dataset before use.

Pull requests that add or correct a paper are welcome.
